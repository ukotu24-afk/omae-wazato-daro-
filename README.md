# お前、わざとだろ。 (試作版 v0.1)

3〜6人向けの協力×人狼パーティーゲーム。スマホ・PCで同じURLから遊べます。

## 起動

```bash
npm install
npm start
```

http://localhost:3000 を開いてください。オンラインで複数人が遊ぶには、RenderなどにNode Web Serviceとしてデプロイします。Start commandは `npm start`。

## 実装済み
- 秘密基地風ロビー、招待URL・コード共有、最大6人
- ブラウザの保存IDによる再接続と部屋復帰（サーバー再起動時は消去）
- リーダー権限譲渡、全員READY、設定変更
- 3/5/7/10ラウンド、難易度、ランダム/毎回選択、重複許可
- 6種類の動作するミニゲーム、ポイント集計、隠された人狼役職、最後の公開
- Web Audioによる簡易オリジナルBGMと効果音、別々の音量・ミュート、端末保存

## 試作版の注意
- **ミニゲームは6種類**。目標の15種類へ今後拡張します。
- 現段階ではゲーム性の検証用で、プレイ操作はシンプルです。複雑な役割分担型・情報分散型は未実装です。
- 部屋はサーバーのメモリに保持するため、再起動・スリープで消えます。永続化にはRedis等が必要です。
- 招待先がスマホで別アプリに移動しても、復帰時にSocket.IOが再接続します。ただしブラウザOSによるタブ破棄やサーバー停止時は復帰できない場合があります。
- 音楽はブラウザのユーザー操作後に再生されます。
- 本格公開前に人数別バランス、通信負荷、入力同期、サーバー側検証を追加する必要があります。
